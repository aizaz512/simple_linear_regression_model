## 🎯 Overview

This project implements simple linear regression to estimate energy generation/consumption in kWh from panel area. It demonstrates the core ML workflow from data preparation to model training and visualization.

## 🧠 Concepts Demonstrated

- Data loading and cleaning
- Feature/target selection
- Linear regression fundamentals
- Model training
- Prediction
- Visualization and evaluation

## 🛠️ Stack

Python · NumPy · Pandas · Matplotlib
